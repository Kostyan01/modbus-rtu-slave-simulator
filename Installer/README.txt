Modbus RTU Slave Simulator — установка

1. Запустите ModbusRtuSimulator-Setup-1.0.0-x64.exe.
2. При необходимости выберите создание ярлыка на рабочем столе.
3. После установки запустите программу из меню «Пуск» или с рабочего стола.

Установщик включает .NET 8 и не требует отдельно устанавливать .NET Runtime.
Поддерживаются 64-разрядные версии Windows 10 и Windows 11.
Программа устанавливается только для текущего пользователя, права администратора не нужны.

Конфигурации устройств и сценариев сохраняются в выбранные пользователем JSON-файлы.
При переносе на другой компьютер скопируйте нужный JSON-файл и откройте его в программе
(Ctrl+O). Удаление программы не удаляет такие файлы, если они хранятся вне папки установки.

Для работы с последовательными портами на компьютере должен быть установлен драйвер
COM-порта адаптера или устройства.
